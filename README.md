# 📝 审批系统

该项目作为上海电力大学信管Java课设

项目后端基于 Spring Boot 构建，前端采用 Vue.js，实现了流畅的单页应用（SPA）交互



## 🚀 部署指南

### 环境要求
- JDK 21+
- Node.js 16+
- MySQL 8+

### 后端部署
```bash
git clone https://github.com/laiwande/Approval_System.git
cd backend
mvn spring-boot:run
```

### 前端部署
```bash
cd frontend
npm install
npm run dev
```
